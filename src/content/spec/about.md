# 关于我

我是 **Lion**，一名在**嵌入式硬件**和 **AI Agent** 两个方向横跳的开发者：白天和 STM32、ESP32 打交道，晚上调教各种 Agent 框架。

## 我在做什么

- **AI Agent 教程**：从 LLM 基础到多智能体实战，写成了一套 16 篇的系列文章，全部配套可运行代码
- **Agent 工具链**：本地 coding agent、硬件在环验证门（build → flash → boot，Agent 不跑完测试不许说"完成"）
- **智能硬件**：鲸屿 WhaleDock 墨水屏桌搭、睡眠呼吸监测系统
- **知识管理**：自托管 Markdown wiki、面向开发者的 agent skills 套件

## 技术栈

**嵌入式**：C / C++、STM32、ESP32-S3、FreeRTOS
**Agent / LLM**：Python、LangChain、LangGraph、OpenAI Agents SDK、Claude Agent SDK、CrewAI
**Web / 工具**：TypeScript、JavaScript、Node.js
